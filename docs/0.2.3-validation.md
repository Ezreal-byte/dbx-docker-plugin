# 0.2.3 Windows 修正包

日期：2026-10-14。最低 DBX：0.6.43。

## 修正

- 容器分组父行采用宿主 muted 底色，子容器采用正常背景；子行不再命中通用斑马纹。选中、悬停仍有效，深浅主题均适用。
- 四类资源表格移除列宽拖动手柄、键盘调整、宽度保存与读取；移除仅供列宽使用的 `host.storage` 权限。保留排序和端口快捷打开。
- 监控页删除“资源监控”和副标题，保留采样状态、指标卡与图表。
- 文件新建、重命名弹窗改为按钮直接调用及回车提交，增加处理中状态。DBX 的 `PluginWorkbenchHost.vue` 使用 `sandbox="allow-scripts"`，不允许原生表单提交；之前依赖表单 submit，导致点击确定不触发业务请求。
- sh/bash/ash 的交互终端启用当前会话的彩色提示符、`ls --color=auto` 和默认 `LS_COLORS`，使用继承的文件描述符提供启动内容，不改写容器启动配置。保留原有初始化文件加载；遵从 `NO_COLOR`，没有 `/dev/fd` 时回退原命令。带参数的自定义命令与其他 shell 保持原行为。其他程序的输出颜色由程序自己决定，不对普通文本强行添加语法色。

终端启动机制参考 [Bash Startup Files](https://www.gnu.org/software/bash/manual/html_node/Bash-Startup-Files)：交互式 Bash 使用 `--rcfile`，sh 使用 `ENV`。

| 沙箱文件弹窗 | 页面使用 CSP `sandbox allow-scripts`，按钮提交重命名、回车创建文件夹成功，列表刷新可见结果。 |
| 监控 | 标题和副标题不再出现在页面，保留采样状态。 |
| 真实容器文件操作 | 使用包内后端，在临时 Alpine 和 MySQL 8.0.44 容器 `/home` 新建文件夹、文件及重命名，通过；重复目录明确返回错误。 |
| 真实终端 | Alpine sh/ash、MySQL sh/bash 均收到彩色提示符和目录 ANSI 输出，键盘输入及退出正常；`sh -c` 显式命令不受启动逻辑影响。 |
