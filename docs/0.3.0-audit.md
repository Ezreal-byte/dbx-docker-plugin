# 0.3.0 危险操作审计

日期：2026-10-14。范围：0.2.0–0.2.3 工作台、文件、终端及 AI/MCP 相关改动；仅改 Docker 插件。最低宿主 DBX 0.6.43。

## 审计结论

发现的阻塞项已整改，并通过本地静态复核、Go / 前端测试和临时 Docker 容器验证。0.3.0 可提交远端 CI；CI 状态以对应提交的 [GitHub Actions](https://github.com/Ezreal-byte/dbx-docker-plugin/actions/workflows/ci.yml) 记录为准。

## 发现与整改

| 优先级 | 问题 | 整改 |
| --- | --- | --- |
| P1 | 上传同名文件直接截断，未确认；中断可能破坏原文件 | 后端强制绑定预览；UI 覆盖确认；同目录暂存、完整字节数校验、提交前复核；取消保留原文件并清理暂存文件 |
| P1 | 旧删除 / 清理 / Compose RPC 绕过新预览门禁 | 所有公开入口统一校验；无令牌拒绝，参数/连接/状态绑定、五分钟时效、一次性消费 |
| P1 | 工作台已缓存的可写连接可能忽略宿主后续只读标志 | 每次带生命周期的请求使用最新只读/生产标志；连接配置不一致要求重新打开 |
| P2 | 断开网络、覆盖镜像标签无绑定确认 | 接入共享预览和状态复核；UI 展示断网影响、原标签指向 |
| P2 | 编辑弹窗可能遮挡后出现的二次确认 | 确认层级提高，Tab 保持在当前弹窗，Escape 取消；取消不会执行修改 |
| P2 | 暂停、远端推送、部分生产写操作确认不足 | 暂停和推送均二次确认；生产重命名、文件创建/重命名补充确认 |
| P2 | 排队写入期间撤销授权仍可能继续执行 | 获取写锁后复核授权；Compose 替换复核删除权限；保留长期任务撤权取消机制 |
| P2 | 并发预览返回顺序可能错配，预览展示和快照之间可能变化 | 丢弃旧清理请求结果；多查询预览生成后再次核对快照；已有确认不会被另一请求覆盖 |
| P2 | 重命名目标在检查后变成目录可能把源文件移入该目录 | `mv -nT` 禁止覆盖和目录目标转换 |

## 操作门禁矩阵

| 操作 | 工作台确认 | Go 后端保护 |
| --- | --- | --- |
| 停止 / 重启 / 暂停 | 二次确认 | 只读拒绝；AI/MCP 还受连接授权与 DBX 写操作确认约束 |
| 容器 / 镜像 / 网络 / 卷删除 | 预览后确认 | 一次性预览；在用卷、引用镜像、内置网络保护；不强制删除运行容器 |
| 清理 | 候选预览 + 输入确认短语 | 只执行绑定的具体候选；逐项检查变化与部分失败；不调用宽泛删除补充新候选 |
| Compose 创建 / 替换 | 预览后确认 | 配置/目标绑定、串行执行、失败恢复；替换的 AI 权限还需 `remove_container` |
| 断开网络 | 预览 + 确认断开 | 固定网络/容器 ID、状态复核、非强制断开 |
| 镜像标签修改 / 删除 | 预览后确认 | 绑定源镜像、目标标签原指向；删除最后一个标签也按危险操作处理 |
| 容器文件删除 | 路径预览后确认，目录注明递归 | 拒绝根路径和非规范路径，绑定容器 ID 与目标元数据，只读拒绝 |
| 文件上传覆盖 | 覆盖 / 生产上传二次确认 | 无令牌拒绝；拒绝最终路径为符号链接、目录或特殊文件；暂存后提交，原文件不被半截写入 |
| 文件新建 / 重命名 | 名称表单确认；生产环境额外确认 | 不覆盖已有名称；参数作为独立 shell 参数；只读拒绝 |
| 终端 | 生产环境进入时确认 | 只读拒绝；未开放给 AI/MCP；彩色启动只作用于已知交互 shell，不改变自定义带参数命令 |
| 镜像推送 | 展示远端标签并二次确认覆盖风险 | 只读拒绝；原传输通道与取消保留 |

AI/MCP 的文件写入、交互终端和任意 RPC 均未开放。权限默认关闭、连接隔离、宿主/插件只读取并集，以及权限文件损坏时拒绝执行仍然有效。

## 边界与交付

- 插件锁只协调本 sidecar，Docker 没有覆盖所有资源操作的跨客户端事务；其他 Docker 客户端仍可能在最后一次检查和操作之间改变资源。已使用不可变 ID、精确范围、状态复核和非强制操作降低此窗口，不能宣称全局原子事务。
- 文件夹删除确认覆盖该目录树，目录预览是根目标元数据检查，不是全部子文件内容快照。文件替换使用同目录暂存，可能需要额外磁盘空间及修改文件属主的权限，失败时保留原文件；容器不具备所需常见文件命令时明确报错。
- 插件无法代替外部 MCP 客户端取得人类确认。预览令牌不是人类批准，DBX 的白名单、只读与写操作审批继续生效。
- 源码版本、manifest、Go 后端与 npm lockfile 统一为 **0.3.0**。Windows 包：`dist/io.dbx.docker-0.3.0-windows-x64.dbxp`；精确 SHA-256 与大小见同目录 artifact JSON。
- 本次只推送源码和运行 CI，未发布 Release、其他平台安装包或更新上架 PR。
