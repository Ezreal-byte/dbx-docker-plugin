# 0.2.2 Windows 工作台更新

日期：2026-10-14。最低 DBX：0.6.43。只交付 Windows x64 验证包。

## 变更

1. 容器表格使用与其他资源页相同的背景、斑马纹、选中及悬停颜色，适配宿主深浅主题。
2. 四类资源表格都有可见列宽拖动手柄，支持左右方向键调整。使用 DBX `host.storage` 保存宽度，重新打开工作台后恢复；不支持该能力的宿主只保留当前工作台内的调整。新增的存储权限仅用于列宽偏好。
3. 发布到宿主的 TCP 端口以高亮按钮呈现，可在桌面默认浏览器打开；端口列表自动换行。Go 后端从容器 Inspect 核对实际端口映射，使用 HTTP（443/8443 等采用 HTTPS），不接收任意 URL。不为 UDP 或未发布端口提供浏览器入口。连接经隧道且应用端口不可直接访问时，会明确提示单独转发应用端口，不复用 Engine 端口。
4. Compose 改用 CodeMirror 6 编辑器，支持高亮、行号、折叠、缩进、搜索和自动换行。配置文件预览复用同一编辑器并设为只读。识别 YAML、JSON、XML/SVG、properties/INI/env/conf、TOML、Nginx、Shell、Dockerfile；其他文本按纯文本显示。保留原 Compose 预览/重建确认流程。
5. 概览分成状态摘要、运行配置、网络与端口、挂载、可展开环境变量。保留容器 ID 复制、命令复制及退出错误信息。监控标签紧随概览，增加采样提示，调整指标卡片和图表；CPU 纵轴允许多核负载超过 100%。
6. 文件上传/下载与镜像任务统一进入顶部传输记录，显示容器、路径、方向、进度、状态、保存位置和取消入口。移除文件区域下方的任务栏。切换容器或返回列表不会清空文件任务；上传目标在选文件时绑定，取消后停止继续发送数据。关闭整个工作台会取消进行中的任务，记录不跨重启保存。
7. 图片预览支持 PNG、JPEG、GIF、WebP、BMP、ICO。预览读取上限 2 MiB；较大的文本仅显示开头，较大的图片提示下载。SVG/HTML 作为文本高亮，不执行内容。文件传输上限仍为 256 MiB，文件夹仍下载为 tar。
