# 0.2.1 Windows 界面与文件管理修复

日期：2026-10-14。插件 ID：`io.dbx.docker`。最低 DBX：`0.6.43`。

## 本次变更

1. 镜像、卷、网络的名称改为常规前景色：浅色主题为黑色，深色主题跟随宿主。保留点击详情能力。
2. 编辑 Compose 返回可读 YAML，使用容器实际网络、卷名称作为 external 引用，避免重复添加项目前缀。保留入口命令、工作目录、用户、环境变量、标签、健康检查、重启次数及多条端口绑定（含 IPv6）。
3. 资源搜索增加清除按钮和 Esc 清空。
4. 文件右键菜单支持打开/预览、文件下载、文件夹 tar 下载、复制路径、上传、新建文件夹/空文件、重命名、删除、刷新；可用 Shift+F10 和方向键操作。写操作在 Go 后端检查只读限制，创建/重命名拒绝覆盖，删除需确认且禁止操作根目录。
5. xterm.js 会话声明 256 色和真彩色能力，修正系统主题检测；加入 Ctrl/Cmd+F 搜索、全部匹配高亮、上/下一个和清除。
6. 表格缩小单元格内边距，Compose 父行使用灰色背景、子行使用普通背景。资源列表、Inspect、文件列表/预览、Compose 回显、镜像历史、引擎信息、磁盘用量和权限加载时显示骨架屏。
7. AI/MCP 权限增加 AI 图标，Docker Engine JSON、Engine 信息、磁盘占用与清理弹窗增加右上角关闭按钮。

## 边界

- Compose 内容由 Docker Inspect 重建，不是原始文件，不能恢复原注释、变量或 profiles。多副本、多个网络、网络别名/静态地址及不支持的配置会在回显或预览阶段报错，不静默删除这些已识别的设置。仍需在替换前核对生成内容；完整 Compose 支持留在路线图中。
- 文件浏览/创建/重命名/删除依赖容器内 `/bin/sh` 和常见文件命令；文件夹下载使用 Docker Archive API，不依赖容器内 tar。单次下载上限 256 MiB。文件变更仅供工作台使用，不新增 AI/MCP 文件写入工具。
- 终端展示程序输出的 ANSI 颜色并支持搜索高亮；命令输入的语法着色仍取决于容器 shell 自身配置。
